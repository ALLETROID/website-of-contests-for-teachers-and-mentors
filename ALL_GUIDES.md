## 📱 Краткие ссылки

### Запуск локально
```bash
# Backend
cd backend
npm install && npm run prisma:migrate && npm run prisma:seed && npm run dev

# Frontend
cd frontend
npm install && npm run dev
```
Детали: [QUICKSTART.md](QUICKSTART.md)

### Загрузка на GitHub
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```
Детали: [GITHUB_QUICK_START.md](GITHUB_QUICK_START.md)

### Обновление кода
```bash
git add .
git commit -m "Update"
git push
```
Детали: [GIT_COMMANDS_CHEATSHEET.md](GIT_COMMANDS_CHEATSHEET.md)
